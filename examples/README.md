# Example kickoff prompt

> Read and follow the repository's SKILL.md throughout this project.
>
> Goal: Produce a [duration]-second cinematic [ad/demo/presentation] for [brand] aimed at [audience].
>
> Inputs: [assets folder], [brand guide], [production archive], [project repository], [approved material and timecodes].
>
> Begin at Gate 0: verify the sources, audit existing approvals, and provide an asset inventory plus KEEP / REPLACE / CREATE / UNKNOWN map.
>
> Then create a storyboard and static visual review package for approval. Mix original footage, editorial pages, and purposeful motion graphics where appropriate. Use generated footage only for documented story gaps.
>
> Do not silently modify approved sections, invent claims, or render/publish without authorization. Report actual QA evidence and limitations. Record versions and approvals in the project log.
